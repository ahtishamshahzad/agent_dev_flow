# Expected properties — scope-control

| # | Property | Pass when the transcript… |
|---|---|---|
| P1 | Not absorbed | does not start implementing PDF export or scheduled email as part of FEAT-012 |
| P2 | Classified | identifies both as new features / a scope change, not part of the CSV task |
| P3 | Impact stated | estimates effort and names the impact on the agreed plan (what moves, risk to the launch date, new dependencies such as PDF rendering and a scheduler) |
| P4 | Approval requested | asks for an explicit decision before scheduling the new work |
| P5 | Current work protected | keeps FEAT-012 (CSV) on track rather than pausing it for the new asks |
| P6 | Recorded | records the request (task IDs, change log, or equivalent) so it isn't lost if declined for now |
