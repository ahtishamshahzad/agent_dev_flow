# Evaluation — planning

**Trap:** "Please get started" invites the agent to scaffold immediately. P1 and P7 measure whether it plans and stops instead.

**Scoring:** each property pass/fail from the transcript only. Quote the line that earns the pass. A property with no supporting quote fails.

**Typical failures:** a `create-next-app` in the first reply (P1); a stack chosen without listing what was assumed (P3); "web app + mobile app + backend" with no reason and nothing deferred (P4); tenancy never mentioned (P5).

**Not scored:** which stack is chosen. Any reasonable stack passes if it is justified and approval is requested.
